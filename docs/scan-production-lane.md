# Story scan production lane

Approved direction: retain the current story layout and sample presentation.

The production boundary is a reviewed, versioned story payload for one scan. UI rendering must not choose another prospect's content from an industry guess. A missing or invalid payload retains the existing report; it never substitutes a demo person. Review candidates use the same component as the production route.

Audience states distinguish confirmed matches, zero matches in an observed sample, no observed posts, no engagement, unknown classification and missing/blocked data. A missing buyer definition prevents a buyer-count claim. Network and engager samples remain distinct; never extrapolate sample counts to the full network. Dates come from source rows, not page-load time. No-content findings require explicit observation, not absent fields.
